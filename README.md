# UNI Node Express EJS Google Books API
An Express.js web application using EJS templates to interact with the Google Books API. Designed for easy deployment on platforms like Heroku.

## Setup
```bash
npm install
```

## Running the Project
- **Directly**: `node index.js`
- **Via npm**: `npm start` (if defined in package.json)
